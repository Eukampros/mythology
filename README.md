# Mythology

An 8-bit pixel-art game menu: a sky citadel (home), a robot lab (Prologue) and a library (Review).
Plain HTML + SVG, no build step. Open `index.html` in a browser to try it locally.

## Put it on GitHub Pages

1. Create a new **public** repository on GitHub (for example `mythology`).
2. Upload everything in this folder (`index.html`, `README.md` and the `img/` folder) to the repository root.
3. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose branch `main` and folder `/ (root)`, then **Save**.
4. After a minute or two the site is live at `https://<your-username>.github.io/mythology/`.

Pages: `#prologue` opens the robot lab, `#review` opens the library.
